개인정보처리방침

시행일: 2026-11-01

  • Oracle Contacts는 소유자 본인의 구글 계정 하나만 씁니다. 다른 사용자의 정보는 받지 않습니다.
  • 읽고 쓰는 정보: 본인 구글 캘린더 일정, 본인 구글 주소록 연락처(Google Calendar API, Google People API).
  • 쓰는 목적: 본인 일정과 연락처를 조회·정리하는 것뿐입니다. 광고, 판매, 제3자 제공을 하지 않습니다.
  • 보관: 로그인 정보는 소유자의 비밀번호 관리자에 암호화해 보관합니다. 일정·연락처 사본을 따로 서버에 쌓지 않습니다.
  • Google API에서 받은 정보는 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.
  • 철회: 구글 계정 설정 > 보안 > 서드파티 앱 연결에서 언제든 접근을 끊을 수 있습니다.

Privacy Policy (English)

Oracle Contacts accesses only its owner's own Google Calendar and Google Contacts, solely to view and organize them. No data is sold, shared with third parties, or used for advertising. Credentials are stored encrypted in the owner's password manager. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time in Google Account settings.
